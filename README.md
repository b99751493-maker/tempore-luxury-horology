# TEMPORE — Time Is An Art Form

Luxury Swiss Horology Web Experience built with **React.js (JavaScript ES6+)**, **Three.js**, **Framer Motion**, **Tailwind CSS**, and **Lucide React**.

## Quick Start

```bash
npm install
npm run dev
```

## Included Features
- **Interactive 3D Mechanical Watch (Hero)**: Procedural Three.js luxury watch with studio lighting, pointer-responsive parallax, and animated balance wheel & gear train.
- **5-Stage Scroll-Driven 3D Deconstruction**: Sticky viewport transitioning seamlessly across *Complete Architecture → Opening → Internal Mechanism → Exploded View (with 360° drag-to-rotate, Reset View, and Assembled View) → Reassembly*.
- **Signature Collection & Spec Modals**: Interactive timepiece gallery with detailed calibre specifications and Private Acquisition Bag drawer.
- **Mechanical Movement Schematic**: Interactive 2D horological diagram illustrating the Mainspring, Gear Train, Escapement, and Balance Wheel.
- **Bespoke Sur-Mesure Configurator**: Live customization of case metallurgy, Grand Feu dial enamel, strap leather, and open-heart balance aperture with dynamic CHF pricing.
